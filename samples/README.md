# فایل‌های نمونه Excel

این پوشه شامل فایل‌های نمونه برای تست افزونه است.

## نحوه استفاده:

### 1. فایل محصولات (products-sample.csv)

این فایل شامل نمونه محصولات با ستون‌های زیر است:
- **محصول**: نام محصول اصلی
- **طول**: مقدار ویژگی طول
- **رنگ**: مقدار ویژگی رنگ
- **ضخامت**: مقدار ویژگی ضخامت
- **وزن (کیلوگرم)**: وزن محصول برای محاسبه حمل‌ونقل
- **قیمت پایه**: قیمت پایه محصول

**نکته:** ردیف با قیمت پایه `0` به صورت "ناموجود" تنظیم می‌شود.

#### تبدیل به Excel:
1. فایل CSV را در Excel باز کنید
2. File → Save As
3. فرمت را به `.xlsx` تغییر دهید
4. ذخیره کنید

### 2. فایل شهرها (shipping-sample.csv)

این فایل شامل نمونه مسیرهای حمل‌ونقل با ستون‌های زیر است:
- **شهر مبدا**: شهر مبدا
- **شهر مقصد**: شهر مقصد
- **پیکان (تومان)**: هزینه حمل با پیکان (برای وزن ≤ 200 کیلوگرم)
- **مزدا (تومان)**: هزینه حمل با مزدا (برای وزن ≤ 500 کیلوگرم)
- **نیسان (تومان)**: هزینه حمل با نیسان (برای وزن > 500 کیلوگرم)

#### تبدیل به Excel:
1. فایل CSV را در Excel باز کنید
2. File → Save As
3. فرمت را به `.xlsx` تغییر دهید
4. ذخیره کنید

## مراحل تست:

### تست محصولات:
1. به **مدیریت فروشگاه → محصولات** بروید
2. فایل `products-sample.xlsx` را آپلود کنید
3. بررسی کنید که محصولات ایجاد شده‌اند

### تست شهرها:
1. به **مدیریت فروشگاه → حمل‌ونقل** بروید
2. فایل `shipping-sample.xlsx` را آپلود کنید
3. بررسی کنید که مسیرها ایجاد شده‌اند

### تست فرمول:
1. به **مدیریت فروشگاه → فرمول‌ها** بروید
2. محصول "لول" را انتخاب کنید
3. فرمول زیر را وارد کنید:
   ```
   ({length} * {thickness} * {meter} * 0.8) + {base_price}
   ```
4. ذخیره کنید

### تست Front-end:
1. به صفحه محصول "لول" بروید
2. یک Variation انتخاب کنید (مثلاً: طول 10، رنگ قرمز، ضخامت 25)
3. فیلد متراژ ظاهر می‌شود
4. متراژ را وارد کنید (مثلاً 4.8)
5. قیمت محاسبه شده نمایش داده می‌شود

## نکات مهم:

- فایل‌های CSV با encoding UTF-8 هستند
- در Excel، هنگام باز کردن CSV، encoding را UTF-8 انتخاب کنید
- ستون‌ها باید دقیقاً همان نام‌هایی باشند که در فایل نمونه است
- ترتیب ستون‌ها مهم نیست، اما نام‌ها باید دقیق باشند
